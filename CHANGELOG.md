# Changelog

## Unreleased

- Expanded community and contribution guides, support and conduct policies, and a maintainer release guide.
- Added issue forms for bugs, export formats, ideas, and usage questions, plus a pull request template.

## 0.1.0 — 2026-11-08

Initial community release.

- Offline conversion of user-provided export ZIPs, directories, and JSON files.
- Markdown views for observed conversation, project, memory, and account-data shapes.
- Original source bytes, SHA-256 manifest, linked index, and import report.
- New-destination writes, archive path checks, and configurable resource limits.
- Standalone Claude skill, community Claude Code plugin, local CLI, and synthetic demo.

Export formats are observed rather than guaranteed by Anthropic. See the format guide for support boundaries.
