# Installation packages

These versioned packages are a public download channel for Amberkeep. The release page links directly to them so installation does not depend on access to GitHub's release-asset upload service.

The ZIPs are generated by `python3 tools/build_release.py` and copied from `dist/` without modification. Each version's `SHA256SUMS.txt` verifies the skill, plugin, and synthetic-demo archives. These packages contain source code, documentation, artwork, and invented demo data only.

For installation instructions, see the [main README](../README.md) and [installation guide](../docs/INSTALLATION.md).
